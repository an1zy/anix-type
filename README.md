# ANIX Type

> ⚡ Context-aware AI autocompletion & command forge for your terminal.

```
PS C:\projects\my-app> git p·ush -u origin main
```

Press `Tab` or `→` to accept the suggestion.  
Type `?? <what you want to do>` and press `Enter` to forge commands from natural language.

---

## Features

- **⚡ Blazing Fast (<1ms):** Instant heuristic predictions for Git, npm/pnpm, Python, Docker, and project files.
- **🧠 Zero-Cost AI Layer:** Seamless integration with free Groq API (500+ tokens/sec) or local Ollama for natural language command forging.
- **🔒 100% Private & Local First:** Basic suggestions run entirely on your machine without internet.
- **💻 Native Shell Integration:** Works seamlessly inside Windows PowerShell / Terminal (PSReadLine) and Bash/Zsh.

---

## Installation

```bash
pip install anix-type
anix-type install
anix-type start
```
